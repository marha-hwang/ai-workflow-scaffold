**무엇이든 묻거나 작업을 시작하기 전에 `docs/index.md`부터 읽는다.** 문서는 LLM 위키 방식으로 관리한다. 위키가 답을 갖고 있으면 raw를 다시 뒤지지 않는다.

## 문서의 세 층

| 층 | 위치 | 누가 고치나 | 규칙 |
|---|---|---|---|
| raw | `docs/raw/**` | 사람과 LLM | 모든 문서의 원본이다. 누가 고치든 바뀌면 해시 대장이 잡아 ingest한다. LLM이 고쳤다면 같은 작업 안에서 ingest까지 끝낸다 |
| 정본 | `CLAUDE.md`, <소스 옆 spec.md 등> | 소스 작업 | 코드와 함께 바뀌는 계약이다 |
| 위키 | `docs/index.md`, `docs/log.md`, `docs/wiki/**` | LLM | raw와 정본을 컴파일한 층이다. 아래 연산으로 고친다 |

스크립트가 직접 읽거나 쓰는 raw 파일: <목록: 파일 → 스크립트의 경로 상수>. 옮기거나 이름을 바꾸면 그 상수를 같이 고친다.

## 위키를 쓰는 규칙

- **위키만 읽어도 답이 나와야 한다.** raw의 내용을 요약·분류·연결해 담는다. 원문을 통째로 옮기지 않고, 행 단위 조회용 표는 "무엇이 있고 어떻게 읽나"만 적는다.
- **코드와 함께 바뀌는 계약 값은 옮기지 않고 가리킨다.** 금액 계산 규칙, 상태 전이, API 필드, 권한 조건은 정본을 링크하고, 위키에는 왜 있고 어디서 쓰이는지를 적는다.
- 페이지 머리말에 `updated:`와 `sources:`(레포 루트 기준 경로)를 둔다. "~가 없다" 같은 단정에는 확인한 날짜를 붙인다.
- 새 페이지는 질문이 생겼을 때 만든다. 카테고리를 미리 만들지 않는다. 링크는 상대경로 markdown 링크로 쓴다.

## 연산

### Query
1. `docs/index.md`에서 페이지를 고르고 읽는다. 필요하면 `sources:`를 따라 원본을 확인한다.
2. 답에 근거 페이지를 적는다. 위키에 없으면 없다고 말하고 원본에서 찾는다.
3. 여러 파일을 조립해야 나온 답이면 기존 페이지에 합치거나 새 페이지로 **승격**한다.

### Ingest (원천 변경)
`docs/ingested.json`이 원천마다 마지막 ingest 시점의 해시를 갖는다. 훅이 사용자 메시지마다 `python3 docs/lint.py --pending`을 돌려 새 파일·수정·삭제된 원천과 그것을 근거로 쓰는 페이지를 알린다. 실패 문구가 나오면 대기 0건이 아니다. 알림이 오면 **사용자 요청보다 먼저** 수행한다.
1. 대기 파일을 읽는다. 수정이면 `git diff -- <경로>`로 무엇이 바뀌었는지 본다. 키·비밀번호·토큰은 위키로 옮기지 않고 알린다.
2. 알림이 가리킨 페이지를 대조해 고친다. 기존 내용과 어긋나면 한쪽을 지우지 말고 날짜와 함께 나란히 적은 뒤 사용자에게 확인받는다. 삭제된 원천을 쓰던 페이지는 근거를 바꾸거나 내용을 걷어낸다.
3. `sources:`와 `updated:`를 고치고, 새 페이지는 `docs/index.md`에 한 줄 추가한다.
4. `python3 docs/lint.py --mark <반영한 경로>...`. 반영하지 않은 파일은 기록하지 않는다.
5. `docs/log.md`에 한 건 append.
6. `python3 docs/lint.py`가 문제 0건, 대기 0건인지 확인하고, 반영한 것을 두세 줄로 알린 뒤 원래 요청으로 돌아간다.

### Ingest (작업 종료)
소스나 문서를 바꾸는 작업은 끝내기 전에 요청이 없어도 한다. 관련 raw·정본 문서를 갱신하고, 위키(status: 진행과 검증, architecture: 구조·배포, risks: 조용한 실패, decisions/: 결정)를 고친 뒤 위 4~6을 한다. 최종 보고에 "갱신한 문서"와 "갱신이 필요한데 못 한 문서"를 따로 적는다. 실행하지 않은 검증은 통과로 적지 않는다.

### Lint
`python3 docs/lint.py`는 깨진 링크, index 누락, 없는 근거를 문제로, 해시가 바뀐 원천을 대기로 보고한다. 기계는 "근거가 바뀌었다"까지만 안다. 알림이 가리킨 페이지는 읽어서 대조한다.
